# 佳能随身相机对比页

这是可直接发布到 GitHub Pages 的静态网页，首页文件为 `index.html`。页面中的两张佳能产品图从佳能官方网站加载，因此浏览时需要联网。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `powershot-camera-compare`。
2. 把本目录中的 `index.html` 上传到仓库根目录并提交。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 里选择 **Deploy from a branch**，分支选 `main`，目录选 `/(root)`，保存。
5. 等待 Pages 部署完成；站点地址会显示在 Pages 设置页，通常为 `https://你的用户名.github.io/powershot-camera-compare/`。
